Before running

Five requirements. One local workflow.

01Node.js 22+

Required by the Strands TypeScript SDK.

02Bedrock credentials

A short-term key or standard AWS credential chain.

03Model access

Amazon Nova Lite in the configured region.

04Core provider

An authenticated provider such as Codex.

05Target app

Dependencies installed, Git initialized, app running.

PrivacyKeep keys local

Security checkpoint

Callable does not automatically mean safe.

Core inspects

  • Tool inputs and declared effects
  • User and agent authorization needs
  • Origin and sensitive-data scope
  • Quota and replay protection

Core preserves

  • Disposable generation workspace
  • Exact patch identifier
  • Independent build checks
  • Review and execution evidence
